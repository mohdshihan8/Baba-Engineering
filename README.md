# Baba Engineering – Expert Fabrication & Welding

## Overview

This repository contains the front-end source code (`baba.html`) for **Baba Engineering**, a professional fabrication and welding business portfolio. The landing page is designed as a modern, single-page application (SPA) focused on showcasing engineering services, project galleries, and company information with high-end UI/UX interactions.

## Features

- **Gooey Navigation Bar**: A custom-built, interactive navigation menu featuring a liquid/gooey "particle" effect upon hover and selection, built using SVG filters and pure CSS animations.
- **Dynamic Hero Section**: High-impact visually appealing hero section with fluid typography and background blending, containing fading entrance animations and animated statistics.
- **Services Showcase**: A responsive grid layout detailing expert fabrication & welding services, featuring smooth hover interactions and scalable cards.
- **Interactive Project Gallery**: An automated, continuous scroll "train" or marquee effect to seamlessly display gallery images (`.jpeg`, `.jpg`) without user input, enhancing engagement.
- **Modern Styling Architecture**: Utilizes vanilla HTML and CSS, featuring CSS Variables (custom properties) to maintain a cohesive, professional color palette (Royal Blue, Dark themes) and ensuring high performance layout rendering with Flexbox and CSS Grid.
- **Responsive Web Design**: Mobile-friendly scaling ensuring the site looks aesthetic on desktops, tablets, and phones.
